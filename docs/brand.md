# Бренд Puente

Puente — «мост» по-испански. Знак и палитра построены вокруг этой метафоры:
арка перекрывает разрыв, а тёплая точка сверху держит её как замковый камень.

## Знак

Арка над разрывом с терракотовой точкой в вершине. Точка сидит ровно на внешней
кромке дуги — не над ней и не внутри.

Геометрия задана в системе координат `100 × 100`:

| Параметр                | Значение  |
| ----------------------- | --------- |
| Центр дуги              | `50, 65.875` |
| Радиус (по центру штриха) | `26.875` |
| Толщина штриха          | `6.5`     |
| Вылет балок от дуги     | `10.625` влево, `12.5` вправо |
| Центр точки             | `50, 35.75` |
| Радиус точки            | `5`       |

Скругления на всех концах штриха обязательны — они дают знаку мягкость, без них
он читается как инженерный чертёж.

### Два кадрирования

Компонент `resources/js/components/PuenteMark.vue` отдаёт знак в двух видах:

- **обычный** (`viewBox="0 0 100 100"`) — квадрат с воздухом, для больших
  плашек и мест, где знак стоит один;
- **компактный** (`compact`, `viewBox="9.25 30.75 83.375 38.375"`) — кадр
  обрезан по самому рисунку. Нужен везде, где знак работает как иконка: в
  шапке, карточках, подвале. Без него арка занимает лишь среднюю треть высоты
  и в мелком размере выглядит слабой.

### Аватар и мелкие размеры

У исходного логотипа штрих `34/800` и точка Ø`44`. При сжатии до 48 px точка
превращается в едва различимую крапину, а концы балок попадают под круглый
кроп, который применяет YouTube.

Поэтому для аватара сделан отдельный вариант с усиленной геометрией: радиус
`215`, штрих `52`, точка Ø`80`, центр дуги смещён на `527` — композиция
оптически центрирована в круге. Файл: `docs/brand/puente-avatar-800.png`.

## Палитра

| Токен                        | HEX       | Роль                                   |
| ---------------------------- | --------- | -------------------------------------- |
| `--brand-teal`               | `#2B5F5A` | Основной. Текст, тёмные секции, кнопки |
| `--brand-teal-dark`          | `#1F4744` | Наведение на кнопки, глубина           |
| `--brand-teal-light`         | `#3E7C76` | Второстепенные акценты                 |
| `--brand-terracotta`         | `#E8A87C` | Декоративный акцент, точка знака       |
| `--brand-terracotta-deep`    | `#A65E29` | Тот же акцент, но для текста           |
| `--brand-sand`               | `#F7F3EE` | Фон страницы                           |

В Tailwind они доступны как `bg-brand-teal`, `text-brand-terracotta-deep` и так
далее — объявлены в `resources/css/app.css`.

### Контраст

Проверено по WCAG 2.1:

| Пара                                    | Контраст | Вывод                    |
| --------------------------------------- | -------- | ------------------------ |
| `#2B5F5A` на белом                      | 7.27:1   | AAA, годится для текста  |
| Белый на `#2B5F5A`                      | 7.27:1   | AAA                      |
| `#2B5F5A` на `#F7F3EE`                  | 6.58:1   | AA для любого текста     |
| `#E8A87C` на `#2B5F5A`                  | 3.58:1   | Только крупный текст     |
| `#E8A87C` на белом                      | 2.03:1   | **Для текста непригоден** |
| `#A65E29` на белом                      | 4.94:1   | AA, безопасно для текста |

Отсюда правило: светлая терракота `#E8A87C` — только заливка и декор. Как
только акцентный цвет попадает в текст на светлом фоне, берите `#A65E29`.

## Типографика

- **Заголовки** — Lora. Тёплая антиква с полной кириллицей; поддерживает
  русский, украинский и польский без подстановок.
- **Текст** — Inter. Нейтральный гротеск, тоже с кириллицей.

Оба подключаются в `Welcome.vue`. Токен `--font-display` в теме указывает на
Lora с откатом на Georgia.
